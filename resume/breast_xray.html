01 / 개요 · Reading

진단은 숫자가 아니라 방향에서 시작한다

ImageNet 사전학습 ResNet18을 전이학습해 흉부 X-ray를 정상/폐렴으로 분류했다. 최초 baseline은 검증 성능이 높았지만 리더보드에서 0.7964로 급락했고, 이 검증↔리더보드 괴리를 출발점으로 삼았다.

전이학습으로 0.9407, Label Smoothing과 시드 앙상블로 0.9439에 안착시켰다. 그러나 이 프로젝트의 실질적 성과는 점수가 아니라 “왜 0.94에서 정체되는가”를 규명한 과정에 있다. 해상도·대비 정규화·증강·최적화 등 8개 축을 한 번에 하나씩만 바꾸는 단일 변수 실험으로, 병목이 모델 표현력이나 과적합이 아니라 train과 test 사이의 구조적 분포 차이임을 근거와 함께 좁혀갔다. Grad-CAM으로 판단 근거까지 검증해, 성능을 올리는 과정에서 한계를 이해하는 문제 해결 흐름을 완성했다.

02 / 배경 & 문제 정의 · Presenting Problem

높은 검증 성능이 “쓸 수 있다”를 보장하지 않는다

흉부 X-ray 폐렴 판독은 반복적·시간 소모적이며 판독 지연은 곧 위험이다. baseline(SimpleCNN)은 검증 AUC 0.992를 기록하고도 test에서 0.7964로 무너졌다. 같은 출처의 train/val은 잘 맞추지만 test에서 급락한다는 것은, 문제가 성능 부족이 아니라 일반화 격차임을 가리킨다.

이 재정의가 이후 모든 실험 설계의 기준이 되었다. “성능을 더 짜낸다”가 아니라 “분포 차이를 좁힌다”가 진짜 과제였고, 규제·증강처럼 train↔val 내부만 건드리는 기법은 이 격차를 줄이지 못하리라는 가설을 세웠다.

The paradox

Validation AUC 0.9920 — 내부 데이터는 거의 완벽하게 분류. 그런데 Leaderboard 0.7964. 이 두 숫자의 공존이 “과적합”이 아니라 “분포 shift”라는 진단의 첫 단서였다.

형식과 전처리

단일 채널 흉부 X-ray. 전이학습을 위해 grayscale→3채널로 확장, ImageNet mean/std 정규화, 224×224 리사이즈. 학습셋의 약 74%가 폐렴이라 다수 클래스 편향과 Accuracy 왜곡을 유발한다.

핵심 특성 — 분포 shift

train은 폐렴 비율이 높은 데 비해 test는 정상 비율이 상대적으로 높다. 이 train↔test 출력 분포 차이가 리더보드 정체의 구조적 배경이 되었다.

Domain rule

흉부 X-ray는 심장이 좌측에 있는 등 좌우 비대칭이 의학적으로 유의미하다. 일반 이미지에서 흔한 좌우반전(HFlip) 증강은 의도적으로 배제했다 — 데이터의 도메인 지식이 증강 설계를 결정한 사례.

05 / 기술 선정 이유 · Rationale

모든 선택을 데이터 · 모델 · 학습 축으로 분류했다

“좋아 보여서”가 아니라, 각 기법이 어느 축의 어떤 문제를 겨냥하는지 명시했다.

Model axis — 전이학습

ResNet18, layer4 + fc만 학습

소량·분포편향 데이터에서 “더 복잡한 모델”보다 “좋은 사전학습 특징의 도메인 적응”이 robustness에 결정적이라 판단. 초기 블록은 동결(저수준 에지·텍스처 재사용, 과적합 방지), 상위 표현과 헤드만 학습. LR 1e-4로 가중치 보호. ResNet50·DenseNet121은 데이터 대비 과적합·무이득으로 기각.

Data axis — 증강 + 정규화

약한 기하/광도 증강, HFlip 제외

회전·이동·스케일·약한 밝기/대비로 다양성 확보하되 좌우반전은 의학적 이유로 배제. SMOTE는 이미지에 부적합해 class weight로 대체.

Learning axis — 불균형 보정 + LS

class weight + Label Smoothing 0.1

2.89:1 불균형을 class weight로 보정하고, 과확신을 완화하는 Label Smoothing으로 0.9407→0.9423. smoothing 0.05는 비단조 반응 → 강한 신호가 아님을 확인.

Variance axis — 시드 앙상블

세 시드 확률 평균 (풀 데이터 유지)

실측 노이즈(±0.014) 안에서 상단에 안착(0.9439). 각 모델이 풀 데이터를 보는 점이, train 80%만 보는 5-Fold보다 개별 성능을 지켜 유리했다.

Evaluation protocol

이 데이터에서 val AUC는 ≈0.999로 포화돼 변별력이 없다. 포화 구간에서 AUC로 best epoch를 고르면 정작 리더보드 지표인 Accuracy가 나쁜 에포크가 뽑힌다 — 그래서 실제 채점 기준인 ACC를 체크포인트 선택 기준으로 삼았다. 지표 선택은 실험 이전에 확정할 설계 결정임을 배운 지점.

Grad-CAM 판독

정답 폐렴은 활성화가 양측 폐야 중앙부에 집중된 반면, 실패 FN(실제 폐렴, prob 0.097)은 활성화가 폐야가 아닌 가장자리·모서리로 새어나갔다. “폐를 볼 때는 맞히고, 엉뚱한 곳을 볼 때는 틀린다”가 시각적으로 확인됐다. 단 Grad-CAM은 상관이지 인과가 아니며, 활성화 영역을 crop한 실험이 리더보드를 0.8093으로 떨어뜨린 것이 이를 뒷받침한다.

Core insight

절대 개선의 대부분은 전이학습(+0.144) — 나머지를 다 합친 것보다 압도적. 그리고 병목은 과적합이 아니라 train↔test 분포 shift다. 결정적 단서는 증강을 4배 강화해도 val이 안 떨어진다는 사실 — train↔val 내부엔 애초에 교란할 출처 변동이 없다는 뜻이고, 곧 분포 차이가 문제임을 확정했다. 오분류의 47.8%가 확률 경계(0.4~0.6)에 몰린 점은 test의 본질적 모호성을, ±0.014 노이즈 실측은 측정 한계를 함께 가리킨다. 실패한 실험이 진단을 정교하게 만든 대표 사례다.

07 / 프로젝트 리뷰 · Retrospective

점수보다 진단 과정이 역량이었다

문제 재정의

검증↔리더보드 괴리를 “성능 부족”이 아닌 “일반화 격차”로 읽은 것이 방향을 결정했다. 오독했다면 모델 크기·에포크를 늘리는 데 시간을 낭비했을 것이다.

단일 변수 규율

한 번에 한 축만 바꿔 인과를 분리했기에, 8번의 기각 실험이 각각 “무엇이 병목이 아닌지”의 증거로 쌓였다. 다섯 기법을 묶었던 초기 실패가 이 규율의 필요성을 각인시켰다.

정직한 평가 신호

val AUC 포화를 인지하고 리더보드를 최종 판정 신호로, 검증 지표는 안정성 모니터링용으로 분리. 노이즈 폭(±0.014) 안의 변동은 개선으로 취급하지 않았다.

아쉬운 점 · 배운 점

분포 shift가 근본 원인이라면 내부 데이터 튜닝은 원리적 한계가 있었다. 더 일찍 확정했다면 외부 데이터로 방향을 틀 수 있었을 것 — 다만 그 확정 자체가 통제된 실패로만 얻어졌다.

한계와 발전 방향

  • 한계 — 학습과 다른 기관·장비 영상에서 민감도 저하 예상. 임상적으로 가장 위험한 오류는 폐렴을 놓치는 FN이므로, 배포 시 도메인 적응·threshold 재보정·정기 재학습 필요.
  • 서비스 확장 — 결과 데이터를 pred_label / probability / risk_level(HIGH≥0.8 · MEDIUM≥0.5 · LOW≥0.2 · NORMAL) / Grad-CAM 근거로 정의해 위험도 우선순위 판독 흐름에 연결.
  • 근본 해법 — 외부 데이터로 출처 다양성 확보. 그 외 test-time 도메인 적응, 병변 위치 기반 해석성 강화(SE Block 등).

이 프로젝트의 성과는 리더보드 0.9439라는 숫자보다, 단일 변수 실험을 반복해 정체의 원인을 근거와 함께 좁혀간 문제 해결 과정에 있다. 점수를 올리는 동시에 모델의 한계를 이해하고, 그 이해를 근거로 데이터와 평가를 다룬 것이 핵심 역량이었다.
