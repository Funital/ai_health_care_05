01 — Overview

개요

영국 인간수정 및 배아연구원(HFEA)의 실제 난임 시술 기록 데이터를 활용해 특정 시술 주기에서 임신이 성공할지 여부를 예측하는 이진 분류 모델을 개발했습니다. 평가 지표는 ROC-AUC이며, 데이터의 심각한 클래스 불균형(성공 약 26%)과 68개 피처의 혼합 타입(범주형·연속형·순서형)이 핵심 도전 요소였습니다.

LightGBM · XGBoost · CatBoost 3개 모델을 10-Fold × 3-Seed OOF 스태킹으로 결합하고, Optuna 베이지안 최적화와 OOF 타겟 인코딩을 파이프라인에 통합해 최종 LB AUC 0.74172를 달성했습니다.

02 — Background & Problem

프로젝트 배경 & 문제 정의

난임 시술은 높은 비용과 신체적·심리적 부담을 수반하며, 성공률 예측은 환자와 의료진 모두에게 중요한 의사결정 근거가 됩니다. 이 프로젝트는 시술 유형, 배아 품질, 나이, 과거 시술 이력 등 다양한 임상 변수를 학습해 개별 주기의 임신 성공 확률을 수치화하는 것을 목표로 합니다.

핵심 문제
클래스 불균형(실패 74.2% / 성공 25.8%), 의료 도메인 특유의 구조적 결측치, 고카디널리티 범주형 변수의 인코딩 누수 방지가 모델 성능을 결정하는 주요 변수였습니다.

05 — Rationale

기술 선정 이유

GBDT 3종 앙상블 — LGB · XGB · CatBoost
탭형 데이터에서 신경망보다 안정적인 성능을 보이는 그래디언트 부스팅 계열을 선택했습니다. 3종 모두 결측치와 범주형 변수를 내부적으로 처리하며, 서로 다른 트리 성장 알고리즘(Leaf-wise / Depth-wise / Symmetric)으로 앙상블 다양성을 확보했습니다.
Optuna TPESampler — GridSearch 대비 효율
25만 건 × 3모델의 파라미터 공간을 GridSearch로 탐색하면 비현실적인 시간이 소요됩니다. Optuna의 베이지안 최적화는 동일한 trial 수에서 더 좋은 파라미터를 찾으며, MedianPruner로 저성능 trial을 조기 중단해 시간을 절약했습니다.
OOF 타겟 인코딩 — 데이터 누수 방지
범주형 변수에 전체 train 기준 타겟 인코딩을 적용하면 validation fold에 타겟 정보가 새어 OOF AUC가 과장됩니다. Fold 내부 train 데이터로만 인코딩 맵을 생성하는 OOF 방식을 적용해 실제 LB와의 괴리를 최소화했습니다.
LogisticRegression 메타모델 — 스태킹 과적합 방지
메타모델 입력이 3개(lgb_oof, xgb_oof, cat_oof)에 불과해 복잡한 메타모델은 과적합 위험이 있습니다. 정규화가 기본 내장된 LogisticRegression을 선택해 각 모델의 기여도를 선형으로 학습했습니다.

핵심 도메인 인사이트

배아 이식 5일차의 의미
배반포(Blastocyst) 단계까지 배양된 배아를 이식하는 5일차 이식은 3일차 이식 대비 착상률이 높습니다. 데이터에서도 5일 이상 시 성공률이 20%p 이상 차이나며 가장 강한 단일 시그널이었습니다.
기증 난자와 나이 보정
Donor Egg IVF에서는 배아 품질이 수혜자 나이가 아닌 기증자 나이에 의존합니다. effective_maternal_age 피처가 FI 2위를 차지하며 이 도메인 지식이 모델에 실질적으로 기여했습니다.
클래스 불균형 처리
성공(26%) / 실패(74%) 비율에 맞게 scale_pos_weight를 데이터 기반으로 자동 계산해 모델에 적용. 임계값 조정보다 AUC 기반 최적화에 집중했습니다.
OOF ≠ LB의 교훈
OOF AUC가 개선되어도 LB가 내려가는 패턴이 반복됐습니다. Train과 Test 분포 차이로 인해 OOF 과신이 실험 방향을 잘못 이끌 수 있음을 실제로 경험했습니다.
07 — Review

프로젝트 리뷰

잘한 점
OOF 타겟 인코딩으로 데이터 누수를 구조적으로 차단했습니다. 발표 전까지 다른 팀들이 놓친 leakage 문제를 초기에 인지하고 설계에 반영한 점이 안정적인 OOF-LB 상관관계를 만든 기반이었습니다.
잘한 점
모든 실험을 LB 제출로 검증하고 기록했습니다. OOF 기준으로만 판단하지 않고 실제 LB 효과를 추적해 "OOF는 올랐지만 LB는 내렸다"는 패턴을 발견하고 실험 전략을 수정할 수 있었습니다.
잘한 점
도메인 지식을 피처에 직접 반영했습니다. 배아 이식 경과일의 임상적 의미를 데이터로 검증하고 이진 피처로 변환해 유일한 LB 개선을 이끌었습니다.
아쉬운 점
전처리 순서와 구조적 결측치 처리가 부족했습니다. DI 시술에서 배아 변수가 구조적으로 결측되는 패턴을 단순 0 대체가 아닌 Missing Flag로 표현했다면 추가 신호를 얻었을 수 있습니다.
아쉬운 점
모델 다양성 확보가 미흡했습니다. LGB · XGB · CatBoost 모두 GBDT 계열이라 상관관계가 높고(~0.999) 앙상블 효과가 제한됐습니다. RandomForest나 ExtraTrees 같은 다른 계열 모델을 포함했다면 더 높은 다양성을 확보할 수 있었습니다.
아쉬운 점
의학 도메인에서 유의미한 변수 조합을 더 찾지 못했습니다. 나이 구간별 임계 효과(38~39세 성공률 급락), 시술 유형별 프로토콜 차이 등 임상적으로 알려진 패턴을 피처로 구조화하는 시도가 부족했습니다.
다음엔
OOF와 LB의 상관관계를 초반에 빠르게 파악하는 실험 프레임워크를 먼저 구축하겠습니다. 또한 피처 추가보다 데이터 전처리 품질에 더 많은 시간을 투자하고, 이기종 모델(트리 + 신경망) 앙상블을 GPU 환경에서 처음부터 설계에 포함시키겠습니다.
